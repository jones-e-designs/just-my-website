A child theme for Blocksy by Creative Themes. Works best with Captain Max.

== Description ==

Just My Website is a child theme for the free Blocksy theme. Install Blocksy first.

* Plugin checklist under Appearance › Just My Website, with Install and Activate buttons.
* Pages whose web address starts with "preview-" stay out of search engines, the sitemap and site search.
* Modern Events Calendar follows your Blocksy colours and fonts.
* Update notices in WordPress when a new version is released.

Captain Max can look after your Just My Website site for you: https://captainmax.ai/websites/
