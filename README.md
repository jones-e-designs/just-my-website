# Just My Website

A child theme for [Blocksy](https://creativethemes.com/blocksy/) by Creative Themes, from [Jones E Designs](https://jonesedesigns.com/).
It requires the free Blocksy theme.

![Just My Website](screenshot.jpg)

## What it adds

- **Plugin checklist:** under Appearance › Just My Website, with Install and Activate buttons, plus a dashboard notice until everything is in place.
- **Login screens** use your logo and Blocksy colours.
- **Preview pages:** pages whose web address starts with `preview-` stay out of search engines, the sitemap and the site's own search.
- **Modern Events Calendar** follows your Blocksy colours and fonts.
- **Update notices:** WordPress shows "Update available" when a new version is released here.

## Install

1. Install and activate the free **Blocksy** theme (Appearance › Themes › Add New).
2. Download `just-my-website.zip` from the [latest release](https://github.com/jones-e-designs/just-my-website/releases/latest).
3. Go to Appearance › Themes › Add New › Upload Theme, upload the zip, and activate **Just My Website**.
